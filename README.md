## 📖 这是什么？

**FDE（Forward Deployment Engineer，前沿部署工程师）** 是 AI 时代最热门的技术岗位之一 —— 把通用大模型能力真正部署到客户复杂业务环境中，并让它**稳定跑出业务价值**。

本指南是一份**系统化、模块化、可落地**的中文 FDE 手册，基于对国内外 8 家大厂 + 3 家 AI 原生公司 + 海外 5+ 家公司的招聘 JD 与技术博客深度调研整理。

无论你是：

- 🎓 **学生 / 求职者** —— 想了解这个 AI 时代最性感的岗位
- 💼 **在职工程师** —— 想从开发转型到 FDE
- 🤝 **非技术岗（产品 / 咨询 / 销售）** —— 想理解 FDE 工作方式以便协作
- 🧑‍🏫 **HR / 招聘官** —— 想了解 FDE 该招什么样的人

都能从这里找到你需要的答案。

## 🚀 快速开始

### 阅读方式

#### 方式 1：在线阅读（推荐）

直接浏览 [GitHub 仓库](https://github.com/leiak/Lumen-AI-FDE-HandBook) 的 Markdown 文件。

#### 方式 2：本地克隆

```bash
git clone https://github.com/leiak/Lumen-AI-FDE-HandBook.git
cd Lumen-AI-FDE-HandBook

# 用你喜欢的 Markdown 编辑器打开
code README.md
# 或
typora README.md
```

#### 方式 3：生成 PDF / EPUB

```bash
# 安装 pandoc
brew install pandoc  # macOS
# 或
apt install pandoc   # Ubuntu

# 生成 PDF
pandoc README.md -o Lumen-AI-FDE-HandBook.pdf

# 生成 EPUB
pandoc README.md -o Lumen-AI-FDE-HandBook.epub
```

### 阅读建议

- 📖 每章独立可读，章首都有「适合谁 / 学完能掌握什么 / 预计阅读时间」
- 🔗 章节之间有交叉引用，遇到不熟的概念会链接回定义章节
- 💻 代码示例可直接复制运行（Python 3.10+）
- ⏱️ 完整阅读约 12 小时（按建议路径）

- ✅ 故障排查手册 + 面试题精选

### 2️⃣ 行业 Know-how 覆盖

针对不同行业的差异化要求做了深度对比：

| 行业 | 重点 |
|------|------|
| 🏦 金融 | 合规、等保三级、数据脱敏、国产化 |
| 🏛️ 政企 | 信创、离线部署、国密算法 |
| 🌐 互联网 | 性能、弹性、API 优先 |
| 🏥 医疗 | HIPAA、免责声明、医学专用 |
| ⚖️ 法律 | 法条准确性、时效性、GraphRAG |
| 🎓 教育 | 内容适宜性、个性化、价值观 |

### 3️⃣ 真实场景实战案例

- 股份制商业银行 RAG 私有化部署（K8s 集群）

## 一、FDE 硬技能 5 层金字塔

```
第一层（必备，100% 公司要求）
  ├─ 编程语言：Python
  ├─ LLM 技术栈：Prompt / RAG / Agent
  ├─ 云原生：Docker / K8s
  └─ 客户沟通能力

第二层（高频，80%+ 公司要求）
  ├─ LLM 框架：LangChain / LlamaIndex
  ├─ 向量数据库
  ├─ Linux 系统管理
  ├─ 私有化部署
  └─ 推理框架：vLLM / TGI

第三层（差异化，30-50% 公司要求）
  ├─ Java 后端能力
  ├─ GPU 编程 / CUDA
  ├─ Fine-tuning / LoRA
  ├─ 评测体系搭建
  └─ Prompt 工程化

第四层（行业专精，按需深耕）
  ├─ 金融：合规、隐私计算
  ├─ 政企：信创生态
  ├─ 零售/电商：推荐、搜索
  ├─ 制造：MES / ERP 集成
  └─ 医疗：HIPAA、临床数据

第五层（2026+ 趋势）
  ├─ Skills 体系设计
  ├─ Context Engineering
  ├─ Multi-Agent 编排（MCP / A2A）
  └─ AI 工具熟练度（Cursor / Claude Code）
```

## 三、阅读路径建议

### 3.1 入门 FDE（0-3 个月）
按顺序读：
1. **2.1.1 编程语言**（打基础）
2. **2.1.2 LLM 技术栈**（核心 ⭐）
3. **2.1.3 云原生**（工程基础）

### 3.2 进阶 FDE（3-12 个月）
按需深耕：
4. **2.1.5 向量与数据**（RAG 进阶）
5. **2.1.6 系统集成**（落地能力）
6. **2.1.4 GPU 与性能调优**（性能优化）

### 3.3 高级 FDE（1+ 年）
全栈能力：
7. **2.1.8 评估工程**（质量保障）
8. **2.1.7 安全合规**（企业级必备）

### 3.4 按问题查询
- **RAG 效果差** → 2.1.2（Prompt/Embedding/Rerank）+ 2.1.5（向量库调优）+ 2.1.8（评估）
- **集成翻车** → 2.1.6（系统集成）+ 2.1.7（安全合规）
- **性能慢 / 成本高** → 2.1.4（GPU 调优）+ 2.1.2（Prompt 优化）

## 六、技术栈选型速查

### 6.1 LLM 框架
- **LangChain**：通用、生态全
- **LlamaIndex**：RAG 友好
- **Haystack**：搜索强
- **DSPy**：编译优化
- **自研**：性能极致

### 6.2 向量库
- **Milvus**：大规模、生产级
- **Qdrant**：轻量、易用
- **Weaviate**：GraphQL 友好
- **Chroma**：原型、本地
- **PGVector**：PostgreSQL 集成

### 6.3 推理框架
- **vLLM**：高吞吐、生产首选
- **TGI**：HuggingFace 出品
- **Triton**：NVIDIA、复杂场景
- **LMDeploy**：清华、量化强
- **自研**：极致性能

### 6.4 评估工具
- **DeepEval**：单元测试风格
- **RAGAS**：RAG 专项
- **LangSmith**：LangChain 生态
- **Langfuse**：开源、可自托管
- **Phoenix**：可视化

> 详细选型决策树见各子文件

## 二、互联网大厂系（8 家）

### 2.1 字节跳动 · 火山引擎 — 零售/电商 FDE

**行业侧重**：零售/电商大客户

**核心职责**：
- 端到端交付大客户大模型 + Agent 项目
- 主导 RAG / Agent 方案落地、压测、调优
- 与产品/算法联动，把客户共性需求沉淀

**技能要求（重点）**：
- 3 年以上 AI 应用落地经验
- Python（主力），Go / Java 加分
- **Vibe Coding 类工具**（Cursor、Claude Code）
- 推理框架（TensorRT / ONNX Runtime / vLLM / TGI）
- 行业 Know-how（推荐、搜索、客服、运营）

**差异化标签**：**Vibe Coding** + **行业 Know-how** + **推理框架深度调优**

**薪资范围**：35K – 70K 月薪，年薪上限 ≈ 105 万

### 2.2 阿里云 — 4 个细分 FDE 角色

阿里云对 FDE 角色做了**最精细的拆分**：

**(a) 政企事业部 · 大模型 FDE**
- 必须懂**国产化信创**生态（昇腾、海光、麒麟 OS、达梦 DB）
- 合规、涉密项目经验是关键门槛

**(b) 智能集团 · Forward 知识工程 & 智能服务 FDE**
- 核心：知识工程（KG + RAG 混合架构）、智能客服、智能文档处理
- 把客户私域知识做成可推理的智能体

**(c) 智能集团 · 智能服务 FDE**
- 偏客服 / 营销 / 售后场景的对话系统
- 强调**多轮对话状态管理**、**意图识别**、**坐席辅助**

**(d) 诚云科技 · 阿里云 FDE 体系内包服务商**
- 偏项目化交付，节奏更快
- 适合希望快速积累项目经验的新人

**共同四大核心能力**：
1. **架构拆解**：把模糊业务问题拆成可工程化的子模块
2. **工具调用与上下文工程**：Agent Tool Use + Context Engineering
3. **评测可观测性**：搭建 LLM 效果评估体系、Trace 工具
4. **生产可靠性**：性能压测、容灾降级、限流、灰度发布

**特色**：完善的 **FDE 认证体系**（FDE-Associate / Professional / Expert），类似 AWS 架构师认证路线

**薪资范围**：20K – 50K 月薪，年薪上限 ≈ 60-80 万

### 2.3 腾讯云 · FDE

**行业侧重**：金融、政务、教育

**核心职责**：
- 主导混元大模型 / DeepSeek 第三方模型交付
- 企业微信、腾讯会议、文档等内部产品 AI 化集成

**技能要求**：
- 熟悉腾讯云 TKE
- 至少 1 个完整大模型项目交付
- 金融 / 政企 IT 架构理解
- 加分：混元 API 实际调用经验

**薪资范围**：25K – 45K 月薪，年薪上限 ≈ 60 万

### 2.4 百度 · DuMate FDE

**行业侧重**：制造业、能源

**核心职责**：
- 基于文心大模型 + 智能体平台 DuMate 做企业交付
- 重视搜索 / 知识中台场景

**技能要求**：
- 文心系列模型深入理解
- DuMate Agent 平台二次开发
- 搜索 / 知识图谱 / RAG 融合方案
- BML 平台使用经验

**差异化**：**搜索 + LLM 融合**、百度传统强项

**薪资范围**：25K – 50K 月薪，年薪上限 ≈ 60 万

### 2.5 蚂蚁集团 · AI FDE

**行业侧重**：金融

**核心职责**：
- 蚂蚁链、蚂蚁金融科技客户的 AI 升级
- 重点：智能风控、智能投顾、智能客服
- 私有化部署、严苛合规

**技能要求**：
- **金融行业背景**（强烈偏好）
- 至少 3 年 Java 经验 + Python
- 熟悉 SOFAStack（蚂蚁自研金融级分布式架构）
- 数据安全、隐私计算（同态加密、联邦学习）

**差异化**：**金融合规 + 隐私计算**

**薪资范围**：30K – 60K 月薪，年薪上限 ≈ 80 万

### 2.6 华为云 · FDE（公开 JD 最详细的一家）

**6 大核心职责模块**：
1. 客户驻场交付
2. AI 智能体开发（盘古大模型 + 昇腾算力）
3. 系统集成（OA/ERP/MES/WMS）
4. 售前售后支持
5. 交付模式沉淀
6. 客户赋能

**技能要求（最全面）**：

| 维度 | 必备要求 | 加分项 |
|------|---------|--------|
| 编程 | Python（主力）、Java | C++ / Go / TypeScript |
| LLM | 盘古大模型、昇思 MindSpore | 主流开源模型（Qwen / DeepSeek / Llama） |
| Agent | LangChain / LlamaIndex / Dify | 自研 Agent 框架 |
| 推理 | vLLM / TGI / TensorRT | 昇腾 CANN 算子开发 |
| 数据 | 向量库 + Elasticsearch | 图数据库（Neo4j） |
| 云原生 | Docker / K8s / Istio | 华为云 CCE 深度使用 |
| 行业 | 制造 / 能源 / 政企 / 金融 | 多行业背景 |
| 软实力 | 抗压、客户沟通、文档能力 | PMP 认证 |

**差异化标签**：**国产化全栈**（昇腾 + 欧拉 + 高斯 DB + 鸿蒙）+ **政企大客户经验**

**薪资范围**：25K – 45K 月薪，年薪上限 ≈ 60 万

### 2.7 美团 · CatPaw FDE

**行业侧重**：本地生活（内部业务线）

**核心职责**：
- 负责美团内部业务线（外卖、到店、酒旅）AI Agent 化
- 基于内部平台 CatPaw 做 Agent 构建
- 与业务团队深度共担 OKR

**技能要求**：
- Java / Spring Boot / Go / Python / React
- Skills / Subagent / Managed Agents 调度
- 美团内部数据中台使用

**差异化**：偏向**内部业务赋能**而非外部客户交付，更接近"业务 FDE"

## 三、AI 原生公司（3 家）

### 3.1 智谱 AI · FDE

**行业侧重**：央国企/金融

**核心职责**：
- 服务于央国企 / 金融大客户的 GLM 大模型私有化部署
- 深入硬件层：GPU 集群规划、InfiniBand 网络调优

**技能要求**：
- **深度学习框架**：PyTorch 源码级理解
- **GPU 编程**：CUDA / NCCL / TensorRT 优化
- **推理框架**：vLLM / SGLang / TensorRT-LLM 至少 2 个
- **集群**：NVIDIA H100 / H200 / A100 集群运维
- **网络**：InfiniBand / RoCE 高速网络调优

**差异化**：**最硬核技术深度**，对标海外 AGI 公司门槛

### 3.2 月之暗面（Moonshot）· FDE

**行业侧重**：金融 / 法律 / 教育

**核心职责**：
- Kimi 大模型的 ToB 落地
- 长上下文（128K-200K）场景的工程化
- 知识型 Agent 交付

**技能要求**：
- **长上下文优化**：KV Cache 优化、Prefix Caching、Chunked Prefill
- **大模型训练 / 推理**：MoE 架构理解、模型并行（TP/PP/EP）
- **RAG 进阶**：GraphRAG、Agentic RAG、Self-RAG
- **数据合成**：高质量训练数据合成 pipeline

### 3.3 DeepSeek · FDE

**行业侧重**：跨行业

**核心职责**：
- V3 / R1 系列模型的企业级部署
- 极致成本优化（DeepSeek 的核心卖点）
- 推理服务的超大规模并发支持

**技能要求**：
- **MLA（Multi-Latent Attention）** 理解
- **MoE 推理优化**：专家路由、负载均衡
- **量化**：FP8 / INT4 / GPTQ
- **成本工程**：TCO 测算、GPU 利用率极致优化

**AI 原生公司共性**：
- 门槛更高（要求真实大模型/GPU 经验）
- 工程师密度高（30-50 人小团队）
- 偏好研究型工程师
- 薪资对标海外大厂

## 四、海外头部公司

### 4.1 Palantir（FDE 鼻祖）

- **起源公司**，最经典 FDE 模型
- **行业**：政府 / 金融 / 医疗
- **特色**：长期驻场 + 深度集成
- **薪资**：$150K – $220K

### 4.2 OpenAI

- **2024 年大规模扩张 FDE**
- **推动 AI 应用落地**
- **薪资**：$170K – $200K（资深总包可达 $550K+）
- **门槛**：技术深度 + 沟通能力双高

### 4.3 Anthropic

- **Claude 模型的 ToB 推广**
- **Skills 体系设计者**
- **偏研究型工程师**
- **薪资**：$170K – $200K

### 4.4 Databricks / Snowflake

- **数据 + AI 平台**
- **偏数据工程型 FDE**
- **薪资**：$150K – $210K

### 4.5 AWS（2026 新设）

- **投入 10 亿美元建 FDE 团队**
- **完善 Amazon Bedrock 生态**
- **薪资**：$140K – $200K

### 4.6 Cohere

- **企业 AI 平台**
- **加拿大公司**，北美市场
- **偏企业集成型 FDE**

## 六、选公司方法论

### 6.1 想要"硬核技术 + AGI 视野"
→ **智谱 / 月之暗面 / DeepSeek**
- 技术深度对标海外 AGI 公司
- 30-50 人小团队、工程师密度高
- 偏研究型工程师
- 薪资对标海外大厂

### 6.2 想要"完整方法论 + 长期路径"
→ **阿里云 / 华为云**
- FDE 认证体系最完整
- 多细分角色、可选择面广
- 适合长期发展

### 6.3 想要"行业深耕 + 高薪资"
→ **字节火山 / 蚂蚁**
- 字节：零售/电商行业 Know-how
- 蚂蚁：金融合规 + 高薪
- 行业 Know-how 价值高

### 6.4 想要"内部业务 + 稳定环境"
→ **美团 CatPaw**
- 内部业务赋能、不出差
- 与业务团队深度共担 OKR
- 稳定、长期

### 6.5 想要"金融专精"
→ **蚂蚁 / 腾讯云 / 华为云**
- 蚂蚁：金融 + 隐私计算
- 腾讯云：混元生态
- 华为云：政企金融

## 八、差异化竞争力分析

### 8.1 最像 Palantir 原始定义：**华为云 FDE**
- ✅ 长期驻场
- ✅ 写生产代码
- ✅ 对业务结果负责
- ✅ 反哺产品
- ✅ 体系最完整（华为云 FDE 培训认证覆盖初中高）

### 8.2 最全面技能要求：**华为云 FDE**
- 6 大职责模块
- 8 大技能维度
- 至少 1 个行业 Know-how
- 编程语言覆盖 Python/Java/Go/C++/TypeScript 五种

### 8.3 最硬核技术深度：**智谱 / 月之暗面 / DeepSeek**
- 要求 GPU 编程、模型并行、量化
- 候选人对标海外 AGI 公司门槛
- 适合学术或顶级工程背景

### 8.4 最接地气业务：**美团 CatPaw FDE**
- 内部业务赋能，深度参与业务 OKR
- 技术栈偏传统（Java 核心）
- Agent / Skills 体系建设是亮点

### 8.5 最体系化：**阿里云 FDE**
- 4 个细分角色 × 4 大核心能力 × 3 级认证体系
- 适合想要"路径明确"长期发展的工程师

### 8.6 最适合新人入门：**诚云科技 / 字节火山**
- 诚云：项目制交付节奏快
- 字节：明确给出 Vibe Coding 等现代 AI 工具使用要求
- JD 透明度高，技能清单清晰

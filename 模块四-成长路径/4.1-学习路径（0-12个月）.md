# 4.1 学习路径（0-12 个月）

> 本章适合谁：想系统化转型 FDE 的读者
> 学完能掌握：分阶段学习内容、推荐资源、实战项目
> 预计阅读：20 min
> 版本：v1.0 / 2026-10-13

---

## 一、整体节奏

```
0-3 个月：基础功
4-6 个月：AI 技术栈
7-9 个月：企业级技能
10-12 个月：实战 + 求职
```

> 整个转型期建议 **6-12 个月**全职学习 + 实战

---

## 二、第 0-3 个月：基础功

### 2.1 Python 进阶（3 周）

**核心内容**：
- 高级特性：装饰器、上下文管理器、生成器、asyncio
- 常用库：requests、pandas、numpy、pydantic
- 代码规范：PEP8、类型注解、单元测试
- 工程实践：FastAPI、Django 项目

**学习路径**：
| 周 | 主题 |
|----|------|
| 1 | Python 基础（语法、控制流、函数）|
| 2 | 进阶特性（装饰器、生成器、上下文管理器）|
| 3 | 异步编程（asyncio、aiohttp）|
| 4 | 工程实践（FastAPI、Django）|

**学习资源**：
- 官方文档：docs.python.org
- 视频：莫烦 Python、Corey Schafer
- 书：《流畅的Python》《Python Cookbook》

**每日时间**：2-3 小时

**实战项目**：
- FastAPI 实现一个 Web 服务
- 异步爬虫 + 数据清洗
- CLI 工具（用 Typer / Click）

### 2.2 SQL 强化（2 周）

**核心内容**：
- 增删改查、子查询、JOIN、窗口函数、CTE
- 性能优化：索引、执行计划
- 数据库：PostgreSQL（推荐）、MySQL

**学习资源**：
- 官方文档 + LeetCode SQL 题
- 书：《SQL 必知必会》《高性能 MySQL》

**实战项目**：
- 复杂业务查询（销售统计、用户画像）
- 数据库性能优化案例

### 2.3 Linux 系统（2 周）

**核心内容**：
- 常用命令、Shell 脚本（Bash）
- 用户权限、文件权限
- 网络配置（IP、端口、防火墙）
- 进程管理、服务管理
- 系统监控（top、vmstat、iostat）
- 性能调优

**学习资源**：
- 《鸟哥的Linux私房菜》
- 实验：阿里云 / AWS 免费主机

**实战项目**：
- 编写自动化部署脚本
- 监控系统搭建

### 2.4 Docker / K8s 入门（3 周）

**核心内容**：
- Docker 镜像、容器、Compose
- K8s 基础概念、Pod、Service、Deployment
- 实操：本地 minikube / 云上 ACK / EKS

**学习资源**：
- Docker 官方教程
- Kubernetes 中文社区
- 极客时间：Kubernetes 入门

**实战项目**：
- 容器化 Python 服务
- 多服务编排（FastAPI + Postgres + Redis）
- 部署到 K8s（ACK / EKS / 自建）

### 2.5 产出物（0-3 月）

- ✅ 一个 Python Web 项目（含测试、部署到 K8s）
- ✅ 熟练使用 Linux、SQL
- ✅ Docker / K8s 基础
- ✅ 每周至少 2-3 小时投入

## 三、第 4-6 个月：AI 技术栈

### 3.1 LLM 基础（3 周）

**核心内容**：
- Transformer 架构
- Prompt Engineering
- 主流模型：GPT-4、Claude、Gemini、Qwen、DeepSeek
- API 调用（OpenAI、Anthropic、各开源模型）

**学习路径**：
| 周 | 主题 |
|----|------|
| 1 | Transformer 原理 |
| 2 | Prompt Engineering |
| 3 | API 调用（OpenAI、Anthropic）|

**学习资源**：
- DeepLearning.AI 课程
- 《这就是大模型》

**实战项目**：
- 调用 GPT-4 API 实现问答系统
- 尝试不同的 Prompt Engineering 技术

### 3.2 RAG 实战（4 周）

**核心内容**：
- 文档加载、切分、Embedding
- 向量数据库（Chroma → pgvector → Milvus）
- 检索策略（BM25、向量、混合）
- 进阶：GraphRAG、Agentic RAG、Self-RAG

**学习路径**：
| 周 | 主题 |
|----|------|
| 1 | 文档加载与切分 |
| 2 | Embedding + 向量数据库 |
| 3 | 检索策略 + 重排序 |
| 4 | 进阶 RAG（GraphRAG、Agentic RAG）|

**学习资源**：
- LlamaIndex 官方文档
- LangChain RAG 教程

**实战项目**：
- **项目 1**：基于公司文档的问答系统
- **项目 2**：基于公开数据集的 RAG 应用
- **项目 3**：GraphRAG 实战

### 3.3 Agent 工作流（3 周）

**核心内容**：
- ReAct、Reflection
- LangGraph、AutoGen、CrewAI
- Tool Use 设计
- Multi-Agent 协作

**学习路径**：
| 周 | 主题 |
|----|------|
| 1 | ReAct、Reflection |
| 2 | LangGraph、AutoGen |
| 3 | Multi-Agent 协作 |

**学习资源**：
- LangChain Agents 教程
- Anthropic Building Effective Agents

**实战项目**：
- **项目 1**：单 Agent + 工具使用
- **项目 2**：Multi-Agent 协作
- **项目 3**：Multi-Agent + RAG

### 3.4 LangChain / LlamaIndex（2 周）

**核心内容**：
- LangChain 核心组件
- LlamaIndex 核心组件
- 项目实战：搭建 RAG + Agent

**实战项目**：
- 综合项目：RAG + Agent + Web UI

### 3.5 产出物（4-6 月）

- ✅ 一个 RAG 项目（基于公司文档 / 公开数据集）
- ✅ 一个 Agent 项目（多步推理 + Tool Use）
- ✅ 熟练使用 LangChain 或 LlamaIndex

## 四、第 7-9 个月：企业级技能

### 4.1 SSO / OAuth 实战（2 周）

**核心内容**：
- OAuth 2.0 流程
- OIDC 协议
- SAML 协议
- 实操：接入 Okta / Azure AD

**学习资源**：
- Okta 开发者文档
- 《OAuth 2.0 实战》

**实战项目**：
- 接入 Azure AD / Okta
- 自研 OAuth 2.0 服务

### 4.2 ETL / 数据管道（3 周）

**核心内容**：
- Airflow（任务调度）
- dbt（数据转换）
- Flink / Spark（流批处理）
- 数据建模

**实战项目**：
- Airflow 调度数据 pipeline
- dbt 数据转换
- Flink 实时数据处理

### 4.3 合规框架了解（2 周）

**核心内容**：
- 等保（中国）
- GDPR（欧盟）
- SOC 2（美国）
- HIPAA（医疗）

**学习方式**：
- 读合规框架官方文档
- 读行业白皮书
- 找合规专家交流

### 4.4 云原生进阶（3 周）

**核心内容**：
- Helm Chart 编写
- Istio 服务网格
- CI/CD（GitHub Actions、GitLab CI）
- IaC（Terraform）

**实战项目**：
- 完整 CI/CD pipeline
- Helm Chart 编写
- Terraform 部署基础设施

### 4.5 监控系统（2 周）

**核心内容**：
- Prometheus + Grafana
- 日志收集（ELK / EFK）
- Trace（Jaeger / Zipkin）
- LLM 专属 Trace（Langfuse、LangSmith）

**实战项目**：
- 完整监控系统（Prometheus + Grafana + 日志）
- LLM 可观测性接入

### 4.6 产出物（7-9 月）

- ✅ 一个端到端项目（SSO + ETL + 部署 + 监控）
- ✅ 理解合规要求
- ✅ 云原生进阶能力

## 五、第 10-12 个月：实战 + 求职

### 5.1 实战项目（4 周）

**项目建议**：

#### 5.1.1 项目 A：企业内部知识库
- **场景**：基于公司文档的问答
- **技术**：RAG + Agent + SSO + 部署
- **亮点**：端到端、可演示

#### 5.1.2 项目 B：行业垂直应用
- **场景**：金融风控、医疗问答、法律审查
- **技术**：行业 Know-how + LLM
- **亮点**：业务价值、可量化

#### 5.1.3 项目 C：开源贡献
- **项目**：LangChain、LlamaIndex、Dify
- **贡献**：PR、Issue、文档翻译
- **亮点**：社区影响力

**项目要求**：
- 端到端可运行
- 包含文档、测试、部署
- 有明确的业务价值
- 有可量化的结果

### 5.2 简历准备（2 周）

**核心要点**：
- 突出端到端交付经验
- 量化业务结果（提升 30% 效率、降低 50% 成本）
- 技术栈清晰
- 项目经验有故事
- GitHub 有项目展示

**简历模板**：
- 1-3 年：1 页
- 3-7 年：2 页
- 7+ 年：2-3 页

### 5.3 面试准备（4 周）

**核心内容**：
- 算法题（LeetCode 中等 100 题）
- 系统设计（高频面试题）
- RAG / Agent 设计
- 软技能面试
- 模拟面试

### 5.4 求职投递（持续）

**策略**：
- 优先大厂（阿里云、华为云、字节火山）
- 关注 FDE 储备、解决方案工程师岗位
- 内推优先
- 同时投递 3-5 家公司

### 5.5 产出物（10-12 月）

- ✅ 3-5 个端到端项目（GitHub）
- ✅ 完善的简历
- ✅ 模拟面试通过
- ✅ 拿到 FDE Offer

## 八、避坑指南

### 8.1 不要陷入"资料收集者"
- 现象：买书囤课不学
- 解决：边学边做项目，避免囤课

### 8.2 不要追求完美
- 现象：项目做了一半、觉得不够好就放弃
- 解决：先跑起来，再优化

### 8.3 不要忽视软技能
- 现象：只学技术，不练沟通
- 解决：主动承担跨部门沟通

### 8.4 不要只学技术
- 现象：学了 1 年技术、还是不懂业务
- 解决：深入了解 1-2 个行业

### 8.5 不要临时抱佛脚
- 现象：投简历前才准备
- 解决：每天 2-3 小时，持续 6-12 个月

### 8.6 不要孤军奋战
- 现象：一个人闷头学
- 解决：找学习伙伴、社区、开源项目

## 十、时间安排建议

### 10.1 在职转型者
- **每日**：2-3 小时（下班后、周末）
- **周末**：5-8 小时
- **总计**：每周 15-20 小时
- **完成周期**：12-18 个月

- **每日**：6-8 小时

- **完成周期**：6-9 个月

- **在校**：每周 10-15 小时
- **寒暑假**：全职投入
- **完成周期**：1-2 年
